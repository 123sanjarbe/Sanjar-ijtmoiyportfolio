# Qo'chqorov Sanjar — Shaxsiy Portfolio & IT Koordinatorlik Vitrinasi

> 13 yoshli Full-Stack Dasturchi & Sirdaryo Viloyati IT Koordinatori Sanjar Qo'chqorovning rasmiy interaktiv portfoliossi.

## 🚀 Texnologiyalar Steki
- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animatsiyalar:** [Framer Motion](https://www.framer.com/motion/)
- **3D Effektlar & Parallaks:** GPU-accelerated 3D tilts, magnetic physics
- **Dizayn uslubi:** Obsidian Dark Mode (`#050505`), Electric Cyan (`#00f0ff`), Emerald (`#10b981`)

## 🌟 Asosiy Xususiyatlar
- **3D Hero Qismi:** Sanjar Qo'chqorovning rasmiy fotosurati, sichqoncha harakatiga mos 3D parallaks va aylanuvchi texnologiyalar orbitasi.
- **Kinetik Tipografiya:** Portret ortidan silliq chiqib keluvchi animatsiyalar.
- **Bento Grid Loyihalar:**
  1. **Aqlvoy AI** — 3-5 yoshli bolalar uchun sun'iy intellekt platformasi.
  2. **BookShare+** — O'quvchilar uchun kitob almashish virtual tarmog'i.
  3. **41maktab_bot** — Maktab boshqaruvi va monitoring Telegram boti.
  4. **Sanjar Shop** — Vue 3 admin paneliga ega e-commerce savdo platformasi.
- **Interaktiv Aloqa:** Bevosita Telegram va form orqali bog'lanish tizimi.
